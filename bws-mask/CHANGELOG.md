# Changelog

## 0.1.0

- `/mask` toggles screen-share masking: emails, names before `<email>`, phone numbers, money amounts, keys and tokens,
  home-path account names, your account name and the `terms` option draw as same-length bars in prompts, replies,
  command output, tool rows and tool results. Only the drawing changes.
- Status line while on; the mode survives a hot reload.
- Mask tab for bws-cockpit's dashboard: mode, distinct hidden values per kind (never the values), rules, gaps, and a
  Turn on / Turn off button with its twin `/mask --toggle`.
