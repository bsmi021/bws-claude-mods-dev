# Changelog

## 0.3.0
- Desktop first: Image embeds a real PNG in the Svg, and a Backdrop button draws the scene full window behind frosted panels.

## 0.2.0
- Image mode in the terminal: `/prism image` or `m`, with a fallback to Raster where the terminal cannot show pictures.

## 0.1.0
- First version: `/prism` opens a pane of animated art, Raster in the terminal and Svg on Desktop. Four scenes, four palettes.
